# PWA icons

Place two PNGs here:

- `icon-192.png` — 192×192px
- `icon-512.png` — 512×512px

Both should look good on a dark background (the app uses #0a0a0d). You can:

1. **Generate from a single source image:** use [realfavicongenerator.net](https://realfavicongenerator.net) — upload any image, download the bundle, drop the 192 and 512 here.
2. **Use a placeholder:** any 192/512 PNG works; the PWA will install and run without specific icons but won't look great on the home screen.

The icons are referenced from `/public/manifest.json`.
